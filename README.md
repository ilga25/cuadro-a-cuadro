# Cuadro a Cuadro
Planificador gratuito de una fila de cuadros de tamaños distintos, alineación vertical, posiciones de uno o dos apoyos fijos, impresión y enlace compartido. Cálculos locales; sin dependencias.

Publicación: GitHub Pages desde main, raíz. URL: https://ilga25.github.io/cuadro-a-cuadro/

Verificación: node check.cjs. No admite alambre elástico, herrajes asimétricos ni varias filas. No verifica resistencia o seguridad. El plano no es una plantilla a escala real.
